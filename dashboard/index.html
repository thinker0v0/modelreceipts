    자기평가 순위 vs 증거 순위

    SYNTHETIC · 합성 데이터

    같은 태스크(L2)에서 에이전트가 스스로 매긴 성공 점수의 순위(왼쪽)와 마지막 테스트 통과율의 순위(오른쪽)입니다. 선이 기울거나 교차하면 자기평가가 순위를 바꾼다는 뜻입니다. 공개 임계를 넘은 현장 보고 셀만 쓰고, 방법(하네스)별 셀은 레코드 수로 가중해 모델 단위로 합칩니다.

    ▼ 자기평가가 과대평가 (증거 순위가 더 낮음) ▲ 증거 순위가 더 높음 순위 같음

    페어 모드 맞대결

    SYNTHETIC

    한 사용자가 같은 태스크를 두 모델로 돌린 쌍만 셉니다. 각 쪽의 마지막 테스트 결과로 승패를 정하고, 둘 다 통과·둘 다 실패는 무승부입니다. A 점수 = (A 승 + 무/2) / 판정된 쌍, Wilson 95% CI.

    선호 = 사람의 쌍대 투표(결과 증거 아님), 사용량 = 채택 점유율(품질 신호 아님). 현장 보고와 합치지도, 같은 순위에 넣지도 않습니다.

    데이터 출처

    시드 층은 source_type으로 분리되고 현장 보고와 합산되지 않습니다. Artificial Analysis 데이터와 LMSYS-Chat-1M은 약관상 쓰지 않습니다.

      랭킹 신호는 결과 증거(tests.pass_rate, Wilson 95% CI)입니다. 자기평가 열은 참고용이며 기본 랭킹에 쓰지 않습니다. 현장 보고 셀은 기여자 k명·레코드 n건 이상이고 한 기여자 비중이 상한 이하일 때만 수치를 공개하고, 미달 셀은 존재만 표시합니다. 비용은 클라이언트 보고값이 있으면 그 값을, 없으면 서버가 가격표로 다시 계산한 값(* 표시)을 보여 주며 두 값은 따로 저장됩니다.
