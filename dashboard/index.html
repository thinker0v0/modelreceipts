    자기평가 기반 순위 vs 증거 기반 순위 SYNTHETIC

    같은 태스크 셀(field_report)에서 에이전트가 스스로 매긴 성공 점수의 순위(왼쪽)와 마지막 테스트 통과율의 순위(오른쪽). 선이 교차하면 자기평가가 순위를 왜곡한다는 뜻입니다. 공개 임계를 넘은 셀만 쓰고, 방법(하네스)별 셀은 레코드 수로 가중해 모델 단위로 합칩니다.

    ▼ 자기평가가 과대평가 (증거 순위가 더 낮음) ▲ 증거 순위가 더 높음 순위 동일

    페어 모드: 같은 태스크 A/B 맞대결 SYNTHETIC

    한 사용자가 같은 태스크를 두 모델로 각각 돌린 쌍(pair_id)만 셉니다. 각 쪽의 마지막 테스트 결과로 승패를 정하고, 둘 다 통과·둘 다 실패는 무승부, 한쪽이라도 테스트가 없으면 판정 불가로 뺍니다. A 점수 = (A 승 + 무승부/2) / 판정된 쌍, Wilson 95% CI.

    데이터 출처

      랭킹 신호는 결과 증거(tests.pass_rate, Wilson 95% CI)입니다. 자기평가 열은 참고용이며 기본 랭킹에 쓰지 않습니다. 현장 보고 셀은 기여자 k명·레코드 n건 이상일 때만 수치를 공개하고, 미달 셀은 존재만 표시합니다. 비용은 클라이언트 보고값이 있으면 그 값을, 없으면 서버가 가격표로 다시 계산한 값(서버 표시)을 보여 주며 두 값은 따로 저장됩니다. 레코드 스키마: schema/record.v0.2.schema.json · API: GET /v1/overview(공개) · GET /v1/aggregates/detail(기여자, 서명 필요).
