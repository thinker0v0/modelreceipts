# 대시보드 디자인 참고 (v1.0.0-rc2)

`dashboard/index.html`을 다시 디자인하면서 잘 알려진 모델 리더보드와 개발 도구 대시보드에서 **패턴만** 빌려 왔습니다. 로고, 색, 아이콘, 폰트, 이미지 같은 자산과 문구는 가져오지 않았습니다. 색은 이 저장소의 데이터 시각화 팔레트(파랑·주황·청록·노랑·분홍 순서의 범주 색, 파랑↔빨강 발산 쌍, 회색 중립)를 쓰고, 글꼴은 시스템 sans입니다. 외부 CDN·폰트·추적 스크립트는 없습니다.

형식: **앱 → 패턴 → 어떻게 적용했나 → 무엇을 다르게 했나**

## 1. LMArena 리더보드

- **패턴:** 순위 열, 신뢰구간(CI) 수염, 표본 수(투표 수), 그리고 CI가 겹치면 같은 순위로 묶는 "통계적 순위(rank upper bound)".
- **적용:**
  - 태스크 셀 리더보드의 첫 열이 순위입니다. 그 아래 작은 글씨로 **통계 N**을 붙였습니다. N = 1 + (내 95% CI 상한보다 CI 하한이 높은 셀 수)입니다.
  - 통과율 열은 모든 행이 **같은 0–100% 축**을 공유하는 CI 막대입니다. 점은 점추정, 연한 띠는 Wilson 95% CI, 가운데 세로선은 50%입니다. 행끼리 눈으로 바로 비교할 수 있습니다.
  - 표본 수는 **n / k 배지**로 보여 줍니다. n은 레코드 수, k는 서로 다른 기여자(설치 키) 수입니다. 시드 층에서 k는 출처 수입니다.
  - 선호 시드(LMArena 55k 집계)의 막대에는 대결 수를 "N표"로 붙였습니다.
- **다르게 한 점:**
  - 순위 기준이 사람의 선호 투표가 아니라 **결과 증거(마지막 테스트 통과)** 입니다. 선호 층은 별도 카드에 두고 현장 보고와 절대 같은 표에 넣지 않습니다.
  - 공개 기준(k·n·한 기여자 비중)을 못 넘은 셀도 표에 **"비공개" 행**으로 남깁니다. 수치는 없고 사유만 있습니다. 리더보드에 "없는 셀"을 숨기지 않으려는 선택입니다.
  - Elo/Bradley–Terry 점수 대신 비율과 Wilson CI를 씁니다. 셀마다 과제 집합이 다르므로 점수를 서로 잇지 않습니다.

## 2. OpenRouter 랭킹

- **패턴:** 모델별 토큰 사용 **점유율**을 한 줄의 100% 누적 막대와 순위 범례로 보여 주고, 기간을 바꿔 가며 추이를 봅니다.
- **적용:** 시드 층 카드의 "사용량 점유율" 보기가 상위 5개 모델 + "기타(롱테일)"를 한 줄 100% 막대로 그립니다. 범례에 순위 순서대로 이름과 점유율을 적었습니다. 범주 색은 고정 순서로 배정하고 순위가 바뀌어도 색을 다시 칠하지 않습니다.
- **다르게 한 점:**
  - **시간 추이는 아직 없습니다.** 지금 적재된 사용량 셀은 한 기간(합성 픽스처)뿐이어서, 추이 차트를 그리면 없는 데이터를 있는 것처럼 보이게 됩니다. 화면에도 "기간이 하나뿐이라 시간 추이 대신 한 기간의 점유율만" 보여 준다고 적었습니다.
  - 사용량은 **품질 신호가 아니라고** 카드 설명에 명시합니다. 점유율로 모델을 추천하지 않습니다.
  - 실제 OpenRouter 데이터를 받지 않았으므로 카드에 SYNTHETIC 태그가 붙습니다.

## 3. Artificial Analysis

- **패턴:** 품질(세로) 대 비용(가로) **산점도**, 로그 가격 축, "왼쪽 위가 좋다"는 사분면 안내.
- **적용:**
  - 태스크 셀 카드의 산점도: 가로축은 태스크 1건당 비용(로그 눈금), 세로축은 테스트 통과율입니다. 점마다 세로 수염으로 95% CI를 그렸습니다.
  - **비용 대비 최선 경계(Pareto frontier)** 를 계단선으로 긋고, 경계 위 셀에만 이름을 직접 붙였습니다. 나머지는 툴팁과 아래 표로 봅니다.
  - 산점도와 리더보드는 **같은 필터 한 줄**(데이터 층·L2·방법)을 공유해 두 화면의 숫자가 항상 일치합니다.
- **다르게 한 점:**
  - Artificial Analysis의 **데이터는 쓰지 않습니다**(약관상 시드에서 제외). 빌린 것은 차트 형식뿐입니다.
  - 품질 축이 합성 벤치마크 지수가 아니라 **셀 단위의 실제 테스트 통과율**이고, 불확실성(CI)을 함께 그립니다.
  - 비용이 서버 가격표로 다시 계산한 값이면 표에 `*`를 붙여 클라이언트 보고값과 구분합니다.

## 4. Linear / Vercel 스타일의 개발 대시보드

- **패턴:** 절제된 색(데이터만 색을 가짐), 분명한 글자 크기 단계, 얇은 경계선, 촘촘하지만 차분한 표, 세그먼트 컨트롤과 칩 필터, 키보드 우선 조작.
- **적용:**
  - 글자 크기 단계를 12 / 13 / 14 / 16 / 20 / 28 / 44px로 고정했습니다. 큰 숫자 하나(히어로)와 보조 KPI 네 개로 요약합니다.
  - 표는 행 높이를 일정하게 하고 숫자 열은 `tabular-nums`로 맞췄습니다. 경계선은 1px 헤어라인, 그림자는 히어로와 핵심 카드에만 씁니다.
  - 보기 전환(공개 개요 / 기여자 상세)과 테마(자동 / 라이트 / 다크)는 세그먼트 컨트롤, L2 선택은 칩입니다.
  - 산점도는 초점을 받은 뒤 ←/→/Home/End로 점을 차례로 보고 Esc로 닫습니다. slope chart의 선은 Tab으로 하나씩 초점을 받습니다.
- **다르게 한 점:**
  - 브랜드 색 대신 **데이터 출처 색**을 씁니다. 노란 계열은 오직 "합성(SYNTHETIC)" 표시, 파란 계열은 "공개 데이터" 표시에만 씁니다.
  - 상단 띠, 히어로, KPI, 각 카드 제목, 차트 안의 워터마크("SYNTHETIC SAMPLE")까지 **합성 데이터 표시를 여러 겹으로** 반복합니다. 제품 대시보드라면 과하겠지만, 이 저장소에서는 합성 수치가 실제 결과로 오해되는 것이 가장 큰 위험입니다.

## 5. 이 저장소만의 시그니처: 자기평가 순위 vs 증거 순위

참고한 앱 어디에도 없는, 이 프로젝트의 핵심 그림입니다.

- 왼쪽 축은 에이전트 자기평가(자기주장 점수)의 순위, 오른쪽 축은 테스트 통과율의 순위입니다. 모델마다 선 하나를 긋습니다.
- 선 색은 한 가지 뜻만 가집니다. 빨강은 자기평가가 과대평가한 경우(증거 순위가 더 낮음), 파랑은 증거 순위가 더 높은 경우, 회색은 순위가 같은 경우입니다. 색만으로 구분하지 않도록 ▲/▼ 기호와 범례, 표 보기를 함께 둡니다.
- 칩에 `⇅`가 붙은 L2는 자기평가 1위와 증거 1위가 다른 태스크입니다. 히어로의 큰 숫자가 그 개수입니다.
- 그림 아래 한 문장 캡션이 "자기평가 1위는 누구이고 실제로는 몇 위인지"를 글로 설명합니다.

## 접근성 기본값

- **대비:** 본문·보조·흐린 글자 토큰이 라이트/다크 모두 표면색 대비 4.5:1 이상입니다(흐린 글자 최소 4.8:1). 빨강·파랑을 글자로 쓸 때는 따로 어둡게 만든 텍스트용 토큰을 씁니다.
- **키보드:** 건너뛰기 링크, 모든 컨트롤의 `:focus-visible` 윤곽선, slope 선과 산점도의 키보드 탐색을 지원합니다.
- **스크린 리더:** 차트마다 `aria-label`로 요약을 붙였습니다. 산점도는 선택한 점을 `aria-live`로 읽고, 모든 차트에 표 보기가 있습니다.
- **움직임:** 전환 효과는 `prefers-reduced-motion: no-preference`일 때만 켜집니다.
- **색 대체:** `forced-colors` 모드에서는 범례 견본이 시스템 색으로 바뀌지 않도록 고정합니다.
- **모바일:** 폭 640px 이하에서는 리더보드가 카드로 바뀝니다. 순위, 모델, n·k, CI를 한 덩어리로 유지합니다.
