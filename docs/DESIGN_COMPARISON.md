# 대시보드 디자인 비교 — 1.0.0-rc3, Codex 단계

2026-09-29. 비교 기준은 저장소의 [DESIGN_REFERENCES.md](DESIGN_REFERENCES.md)에 기록된 패턴과 수정 전 `dashboard/index.html`이다. 이번 라운드는 외부 접속 없이 진행했다. 아래 참고 대상은 최신 서비스 화면을 직접 검사한 결과가 아니며, 해당 서비스의 현재 기능·접근성에 대한 평가도 아니다. 로고·브랜드 색·문구·외부 자산을 복제하지 않고 기존 시스템 글꼴과 데이터 팔레트를 유지했다.

| 참고 대상 | 패턴 | 우리 화면 (rc2) | 격차 | 조치 (rc3) |
|---|---|---|---|---|
| Linear / Vercel | 정보 계층과 빠른 섹션 이동 | 긴 페이지를 차례로 스크롤 | 표·출처까지 찾아가는 비용이 큼 | 순위 비교·태스크 셀·시드·출처 앵커 내비게이션 |
| OpenRouter rankings | 데이터 기간과 범위의 명시 | 생성 시각이 맨 아래에만 있음 | 현재 값·실시간 값으로 오해할 수 있음 | 상단 스냅샷 생성 시각, 보기 범위, 실시간 갱신 아님 표시 |
| Linear / Vercel | 진행 중 상태의 명확한 피드백 | 로딩 문구 한 줄과 비어 있는 본문 | 진행 중인지 멈췄는지 알기 어려움 | 움직이지 않는 자리표시 카드, status, aria-busy, 15초 요청 제한 |
| Linear / Vercel | 오류 뒤 복구 행동 | 기술적인 서버 실행 안내만 표시 | 재시도와 데모 진입 경로가 없음 | 다시 불러오기·샘플 보기, 실행 안내는 펼치기, 오류와 빈 데이터 구분 |
| LMArena | 필터 범위와 표본의 가시성 | 필터 값과 행을 따로 읽어야 함 | 결과 수·비공개 수·표시 수를 바로 알 수 없음 | 선택 범위와 공개/비공개/표시 개수를 live status로 제공, n·k 뜻을 표 위에 표시 |
| Linear / Vercel | 필터 초기화와 행동 가능한 빈 상태 | 일치 셀 없음 문구만 있음 | 조건을 되돌리기 어렵고 모바일 빈 행도 부자연스러움 | 독립된 빈 상태와 초기화 버튼, 데이터 자체가 없으면 선택기 비활성화 |
| LMArena | 순위·불확실성을 읽기 쉬운 표 | 여러 숫자 열로 가로 스크롤, 모델 이름을 놓치기 쉬움 | 정렬을 바꾸면 # 의미가 모호하고 결측값도 설명 부족 | 모델 열 고정, 긴 이름 줄바꿈, #는 통과율 순위라는 주석, 결측값 설명, 키보드로 표 스크롤 |

| LMArena / Artificial Analysis | 차트 탐색과 상세 값의 일관성 | 필터 변경 뒤 툴팁이 남고 slope 툴팁 Esc 미지원 | 새 데이터와 이전 선택이 섞여 보일 수 있음 | 산점도 재렌더 시 선택·툴팁 초기화, slope Esc 닫기, 표를 이름 있는 키보드 스크롤 영역으로 제공 |
