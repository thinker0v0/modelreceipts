# 대시보드 디자인 비교 — 1.0.0-rc3 (Codex 단계 → Opus 단계)

2026-09-29. rc3는 두 단계로 진행했다. 먼저 Codex(GPT) 단계가 격차 10개를 찾아 고쳤고(커밋 `0c31c5c`), 이어서 Claude Opus 단계가 그 결과를 검토해 부족한 부분을 보완하고 새 격차 2개를 더 고쳤다. 비교 기준은 저장소의 [DESIGN_REFERENCES.md](DESIGN_REFERENCES.md)에 기록된 패턴과 각 단계 직전의 `dashboard/index.html`이다.

두 단계 모두 외부 사이트에 접속하지 않았다. 따라서 아래 참고 대상 열은 기록해 둔 패턴을 가리킬 뿐이며, 해당 서비스의 최신 화면이나 기능·접근성을 평가한 것이 아니다. 로고·브랜드 색·문구·외부 자산은 복제하지 않았고, 기존 시스템 글꼴과 데이터 팔레트를 그대로 썼다.

"Opus 단계 결과" 열의 뜻은 다음과 같다.

- **유지**: Codex 조치를 검토했고 바꿀 이유가 없었다.
- **보완**: Codex 조치는 유지하면서, 남은 결함이나 새로 생긴 결함을 고쳤다.

## 바꾸지 않은 것

- 통계 산식(Wilson CI, 통계적 순위, Pareto 경계), 데이터 팔레트, 합성·공개 태그의 색과 위치. 상단 띠, 히어로, KPI, 카드 태그, 차트 워터마크에 합성 표시를 여러 겹으로 두는 방식도 그대로 두었다.
- Codex 단계의 빈 상태·오류·로딩 구조, 필터 요약, 44px 조작 영역, 모델 열 고정, 산점도 주석.
- 산점도의 `role="application"`. 화살표 키 탐색을 위해 rc2에서 고른 방식이라 이번에는 건드리지 않았다. 실제 스크린 리더로 확인한 적은 없다.
